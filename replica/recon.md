# Recon: режим «Свой плагин» (abcTrain, macOS)

Дата: 2026-10-23. Методика — replica-recon (github.com/Jakeschincariol/replica-skill, MIT).
Это не клон чужого продукта: «оригиналы» здесь — установленные плагины (их ручки, тексты значений)
и ближайший аналог по сценарию — TrainYourEars. Берём сценарии и функции, не интерфейсы.
Окно плагина в abcTrain показываем **настоящее** (редактор самого плагина), свою графику bx/FabFilter не рисуем.

### Рэки и оболочки (вопрос Богдана)

- **Оболочка (WaveShell)** — один файл, внутри много плагинов. Хост JUCE видит каждый как отдельный плагин после скана: показываем их списком, как обычные.
- **Рэк-плагин (Ozone 12, ShaperBox, masterdesk)** — один плагин с модулями. Хосту видны только параметры, которые рэк выставил наружу.
  Если модуль внутри рэка не публикует параметры — тренировать его нельзя; карточка честно пишет «видно 24 из ~200, остальное внутри рэка». Для Ozone 12 есть отдельные модули (Ozone 12 Equalizer, Dynamics…) — предлагаем их вместо рэка.
- **Рэк, в который пользователь сам добавляет плагины (Kilohearts Snap Heap, PatchWork-подобные)** — параметры меняются при перестановке; профиль ручек привязываем к состоянию рэка и пересканируем при изменении.

## 5. Потоки

```
F01 Первый запуск
    S01 (пусто) -> S02 скан -> S01 (список)                        клики: 2
    edge: плагин падает при скане -> список «не загружается»; плагин в демо -> метка «ненадёжный звук»
F02 Угадай значение (основной цикл, MVP #44)
    S01 -> S03 (зонд, ~20–60 с) -> S04 -> S05 x N -> S09            клики до первого раунда: 3
    edge: ручка не слышна на файле игрока; варианты ближе шага шкалы -> генератор их не ставит
F03 Повтори эталон
    S03 -> S04 (упр. «Повтори») -> S08 x N -> S09
    edge: плагин не восстанавливает состояние -> раунд запрещён, отчёт S10
F04 Поправить роль ручки
    S03 -> карточка -> «исправить» -> профиль плагина сохранён
F05 Рэк
    S01 -> S11 -> «взять модуль отдельно» -> S03 нужного модуля
```

## 6. Компоненты

PluginWindowFrame (настоящее окно плагина: живое / заблокировано / скрыто), KnobRoleRow (роль, уверенность-полоска, слышимость, действие),
ResponseChart (отклик ручки по 33 позициям, ось — текст плагина), ChoiceGrid (2–5 вариантов текстом плагина),
ABSwitch (A мой / B скрытый, кроссфейд, выровненная громкость), DistanceMeter (точно / близко / мимо в долях шага),
ScanProgress, StatusBadge (готов / зонд / не слышно / рэк / падает / демо). Общие с играми: хедер тренировки, пипсы ступени, кнопка подсказки.

## 8. Что не делаем

- Не рисуем интерфейсы чужих плагинов и не берём их графику: показываем их собственный редактор.
- Не публикуем профили чужих плагинов без чтения EULA.
- iOS не хостит десктопные плагины (bx/FabFilter — только Mac): на телефоне только прогресс.
- Анализаторы и инструменты (SPAN, Kontakt, Serum) — не процессоры эффекта, в режим не попадают на старте.

## 9. Размер

12 экранов, 5 потоков, 4 сущности. Тяжёлые места: (1) стабильный хостинг и восстановление состояния чужих плагинов,
(2) зонд + офлайн-рендер с компенсацией latency и хвостов, (3) перцептуальная шкала и её проверка на слух.
Размер: L (квартал) целиком; этап 0 + этап 1 (S01–S05, S09) — M.
