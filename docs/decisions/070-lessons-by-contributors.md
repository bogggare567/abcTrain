# 070 — Уроки от приглашённых авторов: через pull request

2026-10-29. Автор: «проработать логику добавления учебных материалов людьми, чтобы разработка была совместной». Выбран вариант «PR на GitHub + проверка». Пакеты уроков без выпуска и редактор без GitHub отложены.

## Решение

Урок остаётся текстовым файлом в `lessons/` (ADR 052, 068). Совместной разработку делает не новый формат, а путь от чужого файла до выпуска:

- **Как писать и как предлагать** — `lessons/CONTRIBUTING.md` (RU + EN): какой урок, шапка, проверка, три способа предложить, что смотрит рецензент, что происходит после слияния.
- **Шапка гостевого урока:** `author` — так подписывают в приложении, `license` — `CC BY-SA 4.0`, `CC BY 4.0` или `CC0`, `sources`. Код abcTrain остаётся под своей лицензией. Тексты, которые отдают люди, — под открытой лицензией, которую выбрали они: тогда понятно, что можно делать с уроком дальше. Уроки самого проекта (`author: abcTrain`) лицензию не указывают.
- **`tools/LessonCheck`** — небольшая консольная программа на том же коде, что приложение и тесты (`LessonFile`, `KnobGlossary`, `OwnLesson`). Проверяет формат, длину, занятость id и порядка, для `plugin: any` — достижимость каждого числа. С `GITHUB_ACTIONS=true` она печатает аннотации, и ошибка видна на строке файла прямо в PR.
- **Рабочий процесс «Lessons»** на PR, затрагивающих `lessons/`, собирает только LessonCheck: несколько минут вместо получаса полной матрицы. Полная сборка тоже идёт: только она проверяет значения уроков Студии по настоящим диапазонам ручек Learner (`LessonFormatTest`).
- **Три входа:** pull request с git; «Add file» на сайте GitHub, где форк и PR делаются сами; форма issue «Урок» для тех, кто GitHub не знает, — PR оформляем мы, автор остаётся автором.
- **Рецензия:** `.github/CODEOWNERS` назначает владельца на `lessons/`, `shared/i18n/strings/` и `versions.json`. С защитой ветки main без его одобрения влить нельзя. Включается в настройках репозитория: Settings → Branches → Require review from Code Owners.
- **Автор виден:** в окне урока Студии в строке над заголовком, на странице «Свой плагин» перед источниками.
- **Версия уроков** (`versions.json` → `lessons`, ADR 069) поднимается с каждым новым уроком.

## Чего нет и почему

- **Пакеты уроков без выпуска приложения** (как пакеты звуков). Нужны подпись или хотя бы проверка пакета в приложении: урок — чужой текст, и он двигает ручки. Ещё нужна совместимость формата между версиями. Это следующий шаг, когда гостевых уроков станет больше пары.
- **Редактор урока в приложении или на сайте.** Нужен сервер и модерация. Форма issue закрывает ту же потребность без сервера.
