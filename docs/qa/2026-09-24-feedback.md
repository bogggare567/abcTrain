## Как прогнать всё самому (в контейнере)

```
ninja -C build EarTrainerTests ClickMap EditorSnapshots
./build/EarTrainerTests_artefacts/Release/EarTrainerTests
xvfb-run -a ./build/ClickMap_artefacts/Release/ClickMap
for l in en ru uk de fr es it pt pl ja ko zh-Hans; do
  TEXT_AUDIT=1 SNAP_DARK=1 SNAP_SIZE=940x620 xvfb-run -a \
    ./build/EditorSnapshots_artefacts/Release/EditorSnapshots out/$l $l | grep OVERFLOW
done
```
