# Установка

*[English version](Installation)*

## Скачать

В каждом релизе есть установщик под каждую систему, собранный на CI ровно из
того коммита, на который указывает тег:

| Система | Файл |
|---|---|
| macOS | `abcTrain-macOS-<версия>.dmg` |
| Windows | `abcTrain-Windows-<версия>-setup.exe` |
| Linux | `abcTrain-Linux-<версия>.tar.gz` |

**[Последний релиз](https://github.com/bogggare567/abcTrain/releases/latest)**

Файлы `plugins-*.zip` на той же странице — это собранные плагины без
установщика, для тех, кто предпочитает разложить их руками.

## Система вас предупредит. Вот почему

Эти сборки **не подписаны**. Подпись означает покупку сертификата, выданного
на проверенное юридическое лицо, — примерно $99 в год у Apple и $200–500 в
год у windows-центра сертификации. Он не куплен, поэтому любая ОС считает
загрузку пришедшей от того, кого она не может назвать.

Предупреждение честное. Оно говорит, что издатель не подтверждён, а не что с
файлом что-то не так.

### macOS

Правый клик (или Control-клик) по `.pkg` внутри образа → **Открыть** →
**Открыть** ещё раз. Если macOS отказывается наотрез, зайдите в **Системные
настройки → Конфиденциальность и безопасность**, прокрутите до раздела
«Безопасность» и нажмите **Всё равно открыть**. На Sequoia и новее для части
загрузок это единственный путь.

Установщик даёт выбрать, какие из четырёх плагинов ставить и в каких
форматах, и ставить ли для всех пользователей или только для себя.

### Windows

Появится синяя панель «Система Windows защитила ваш компьютер». Нажмите
**Подробнее**, затем **Выполнить в любом случае**. Если сам браузер
заблокировал загрузку, выберите *Сохранить* → *Всё равно сохранить* в списке
загрузок.

### Linux

Никаких привратников. Распакуйте архив и запустите внутри `./install.sh` — он
спросит, какие плагины нужны и куда класть VST3 (`$HOME/.vst3`,
`/usr/lib/vst3` через sudo или путь, который вы наберёте). Если не
запускается, сначала `chmod +x install.sh`.

## Как они называются

| В браузере плагинов | Производитель |
|---|---|
| ABC Ear Trainer | soundkorb |
| ABC Learner EQ | soundkorb |
| ABC Learner Comp | soundkorb |
| ABC Learner Verb | soundkorb |

Переименованы в **v1.3.0**. Если у вас есть проект, сохранённый со старыми
сборками, хост сообщит, что плагины отсутствуют: идентификаторы, по которым
хост их находит, выводятся из имён производителя и продукта, так что для него
это новые плагины. Обойти это нельзя; переименование есть переименование.

## Куда всё попадает

| | macOS | Windows | Linux |
|---|---|---|---|
| VST3 | `/Library/Audio/Plug-Ins/VST3` | `Common Files\VST3` | `~/.vst3` |
| AU | `/Library/Audio/Plug-Ins/Components` | — | — |
| Standalone | `/Applications` | `Program Files\abcTrain` | выбранный вами путь |

Ваш прогресс, уровни, достижения, язык и тема лежат совсем в другом месте, и
ни один установщик их не трогает:

- macOS: `~/Library/Application Support/abcTrain/`
- Windows: `%APPDATA%\abcTrain\`
- Linux: `~/.config/abcTrain/`

## Обновление

Нажмите значок загрузки в верхней строке любого плагина. Он проверит, есть ли
более новый релиз, и если есть — предложит скачать установщик под вашу
систему, скачает его с индикатором прогресса и откроет.

Заменить плагин, который хост уже загрузил, он не может — этого не может ни
одна программа, так устроены загруженные библиотеки, — поэтому **перезапустите
DAW**, чтобы подхватить новую версию. Прогресс сохранится.

## Сборка из исходников

Три команды, и это тот же бинарник, только без предупреждения, которое надо
прокликивать:

```
git clone https://github.com/bogggare567/abcTrain.git
cd abcTrain
cmake -B build && cmake --build build
```

CMake сам скачает JUCE; локальная копия не нужна. На Linux сначала поставьте
`libcurl4-openssl-dev`.
