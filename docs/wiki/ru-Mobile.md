# abcTrain на телефоне и планшете

*[English version](Mobile)*

Мобильная версия — то же приложение: девять упражнений, лестница порогов,
уроки, Live как участник (вход в семинар, батлы). Раскладка своя, под палец:
вкладки внизу, A/B и «Ответить» в нижнем ряду под большим пальцем. Нет только
того, что телефону не положено: своих VST3/AU-плагинов и ведения семинара.

## Android — APK из релиза

1. Откройте [последний релиз](https://github.com/bogggare567/abcTrain/releases/latest)
   с телефона и скачайте `abcTrain-…-android.apk`.
2. Откройте файл. Android спросит, можно ли ставить приложения из этого
   источника (браузера или «Файлов»): разрешите для него.
3. «Установить». Нужен Android 8.0 или новее.

**Обновление:** скачайте новый APK и установите поверх, прогресс
сохранится. Если Android пишет «приложение не установлено» или «конфликт
подписи», значит, старая версия подписана другим ключом. Так бывает с
тестовыми сборками: удалите старую и поставьте новую. Прогресс при этом
пропадёт, поэтому перед удалением войдите в Live, чтобы синхронизировать
сводку.

Google Play — позже.

## iPhone и iPad — сборка из Xcode (бесплатно)

Без App Store поставить приложение на iPhone можно только своей сборкой.
Бесплатный аккаунт Apple даёт подпись на **7 дней**: потом приложение
перестаёт открываться, и его нужно пересобрать. Прогресс при этом не
теряется.

Нужен Mac с Xcode 16 или новее и кабель.

1. **Xcode.** Поставьте из App Store, откройте один раз. Xcode → Settings →
   Accounts → «+» → Apple ID. В списке появится команда «(Personal Team)».
   Её ID — 10 символов, их видно в Settings → Accounts → Manage
   Certificates или в ошибке подписи при первой сборке.
2. **Исходники и CMake:**
   ```
   brew install cmake git
   git clone https://github.com/bogggare567/abcTrain.git
   cd abcTrain
   cmake -B build-ios -G Xcode -DCMAKE_SYSTEM_NAME=iOS -DABCTRAIN_IOS_TEAM=ВАШ_TEAM_ID
   open build-ios/EarTrainer.xcodeproj
   ```
3. **Телефон.** Подключите кабелем, разблокируйте, нажмите «Доверять».
   На iOS 16 и новее включите Настройки → Конфиденциальность и
   безопасность → **Режим разработчика** и перезагрузите телефон.
4. **Сборка.** В Xcode вверху выберите схему **EarTrainer_Standalone** и
   ваш телефон, нажмите ▶. Первая сборка идёт 5–10 минут.
5. **Доверие.** При первом запуске iPhone скажет «Ненадёжный разработчик»:
   Настройки → Основные → **VPN и управление устройством** → ваш Apple ID →
   «Доверять».

Через 7 дней: подключите телефон и снова нажмите ▶ в Xcode. Чтобы
забрать свежую версию, сначала выполните `git pull`.

**Свои звуки на iPhone:** приложение видно в «Файлах» → «На iPhone» →
abcTrain. Положите туда папку со звуками или пакет.

TestFlight (установка по ссылке, без Xcode и без 7 дней) требует платного
Apple Developer Program, $99 в год. Как только он будет, сюда добавится
ссылка.

## Для владельца репозитория: ключ подписи Android

Чтобы APK из разных релизов обновлялись поверх друг друга, все они должны
быть подписаны одним ключом. Создайте его один раз и храните в надёжном
месте: потерянный ключ означает, что всем придётся переустанавливать
приложение.

```
keytool -genkeypair -v -keystore abctrain.keystore -alias abctrain \
  -keyalg RSA -keysize 4096 -validity 36500
base64 -i abctrain.keystore | pbcopy
```

GitHub → Settings → Secrets and variables → Actions:
- `ANDROID_KEYSTORE_BASE64` — то, что скопировалось;
- `ANDROID_KEYSTORE_PASS` — пароль хранилища;
- `ANDROID_KEY_ALIAS` — `abctrain`;
- `ANDROID_KEY_PASS` — пароль ключа.

Без них рабочий процесс «Android» подписывает APK одноразовым ключом и
предупреждает об этом.
