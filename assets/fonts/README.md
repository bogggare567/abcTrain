# Fonts

The interface typeface, embedded rather than assumed to be installed —
a plugin cannot ask its host's machine to have a font.

**Barlow** carries the Latin, at the three widths the design uses:
`Barlow` for body text, `Barlow SemiCondensed` for meta lines and small
labels, `Barlow Condensed` for headings and the wordmark.

**Barlow has no Cyrillic.** That is not an oversight in this repo — the
family ships Latin, Latin-ext and Vietnamese only, so in the original
design mockup every Russian word was already falling back to whatever
the browser had. In a Russian-first app that fallback cannot be left to
the operating system, so the Cyrillic is carried here by **Roboto**,
pinned out of its variable font at the same three widths (`wdth` 100 /
87.5 / 75) so a Russian word beside an English one is the same shape and
the same weight. It is registered under `abcTrain Cyr*` family names
rather than "Roboto" so it can never collide with a Roboto the host
machine already has installed.

Each file is subset to the script it is there for — Barlow to Latin and
Latin-ext, Roboto to Cyrillic — which is what takes twelve faces from
1.3 MB down to 356 KB. CJK is deliberately not embedded: the zh/ja/ko
tables fall through to the system, as every application does.

Both families are SIL Open Font License 1.1 (`OFL-Barlow.txt`,
`OFL-Roboto.txt`), which permits embedding and redistribution in a
commercial product. The OFL requires the licence to travel with the
fonts, which is why both files are here and why the installers ship this
folder.

Regenerated by `tools/build_fonts.py` — sources are Google Fonts
upstream, not committed.
