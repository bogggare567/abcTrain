# Fonts

The interface typeface, embedded rather than assumed to be installed — a
plugin cannot ask its host's machine to have a font.

**Barlow** carries the Latin, at the three widths the design uses:
`Barlow` for body text, `Barlow SemiCondensed` for meta lines and small
labels, `Barlow Condensed` for headings and the wordmark.

## Why there is a second family in here

**Barlow has no Cyrillic.** The family ships Latin, Latin-ext and
Vietnamese and nothing else, so in the original design mockup every
Russian word was already falling back to whatever the browser had. In a
browser that is invisible; in a Russian-first application it is not.

The Cyrillic is therefore carried by a companion, registered under
`abcTrain Cyr*` names so it can never collide with a font the host
machine already has installed. Which companion was not chosen by eye. For
each Barlow cut, `tools/build_fonts.py` measures two things — the
width-to-cap-height ratio of H/O/N, and the ink coverage of the same
three letters, which is a good proxy for stem weight — and searches the
variable axes of the candidates for the closest point.

That search returned **two** companions, and that is the consistent
answer rather than an inconsistent one: Barlow and Barlow Condensed are
already two different designs, so matching each of them separately is the
point.

| Role | Latin | Cyrillic companion |
|---|---|---|
| body | Barlow Regular / Medium | Noto Sans `wdth 80`, `wght 350 / 450` |
| meta | Barlow SemiCondensed Regular / Medium | Noto Sans `wdth 70/62.5`, `wght 350 / 500` |
| headings | Barlow Condensed SemiBold / Bold | Oswald `wght 500 / 600` |

Noto Sans reaches Barlow and Barlow SemiCondensed almost exactly. It
**cannot** reach Barlow Condensed — its narrowest width is still 15% too
wide — which is where Oswald lands, within 3% on width and 1% on weight.
Roboto was tried first and rejected for the same reason: even at `wdth
75` it is wider than Barlow SemiCondensed, let alone Barlow Condensed.

## Vertical metrics

Every companion is scaled and relabelled onto Barlow's own proportions:
1 em of ascent, 0.2 em of descent, a 0.7 em cap height. This is not
tidiness. JUCE scales a typeface by its *own* ascent + descent, so two
families that disagree about those draw at different sizes for one
requested height — the companion was landing 4% larger, which is exactly
visible in a word like "EQ ВЫКЛ" where the two scripts sit side by side.

## Size

Each file is subset to the one script it is there for — Barlow to Latin
and Latin-ext, the companions to Cyrillic — which is what keeps twelve
faces around 650 KB. Combining marks (U+0300–036F) are deliberately
dropped: every accented letter this app can show is a precomposed
codepoint, and keeping the marks drags in the whole GPOS
mark-attachment machinery for glyphs nothing ever asks for, at about
28 KB a face.

CJK is deliberately not embedded: the zh/ja/ko tables fall through to the
system, as every application does.

## Licences

All three families are SIL Open Font License 1.1 (`OFL-Barlow.txt`,
`OFL-NotoSans.txt`, `OFL-Oswald.txt`), which permits embedding and
redistribution in a commercial product. The OFL requires the licence to
travel with the fonts, which is why all three files are here and why the
installers ship this folder.
