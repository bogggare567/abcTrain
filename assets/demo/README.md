# Demo GIFs/video needed here

Same constraint as [`assets/screenshots/`](../screenshots/README.md) — no
display in this sandbox, so no recordings exist yet. If you're picking
this up with a real display available, these are the clips that would
actually sell the product, in priority order:

1. **Playing an EarTrainer round end-to-end** — select a game, hear the
   audio, click a choice, see the correct/wrong feedback and score update.
   ~5-10 seconds.
2. **Dragging an EQ band on LearnerEQ** — show the response curve moving,
   the highlighted frequency region, and the guide-label tooltip text
   updating live. ~5-10 seconds.
3. **A/B via Bypass on LearnerComp or LearnerVerb** on a real audio clip —
   toggling Bypass so the before/after difference is audible in the
   recording. ~10 seconds.
4. **A full "Lesson" walkthrough** on one plugin, sped up 2-4x if it runs
   long. Shows the step text changing and the corresponding knob actually
   moving on its own.
5. **Switching languages** in EarTrainer and showing the game
   name/instructions text changing instantly.

## Format

- GIF (looping, no audio) for README embedding, under ~5 MB each so they
  load reasonably in GitHub's rendered README.
- If you also record with audio (recommended for #1 and #3, since the
  actual sound is the point), keep an MP4/MOV alongside the GIF - GitHub
  READMEs can't embed a video with audio directly, but it's worth having
  for a future proper demo page/social post.
- Name them to match: `eartrainer-round.gif`, `learnereq-drag.gif`,
  `ab-bypass.gif`, `lesson-walkthrough.gif`, `language-switch.gif`.
