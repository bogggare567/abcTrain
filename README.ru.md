# abcTrain

### Научитесь слышать то, о чём вы читали.

Девять упражнений на слух и три настоящих эффекта, которые объясняют сами
себя, работая с вашим звуком. Бесплатно, исходники открыты, macOS · Windows ·
Linux, в форматах VST3 · AU · Standalone.

## Девять упражнений

Четыре просят **значение**, ответ даётся перетаскиванием по шкале. Попадание
в допуск засчитывается; уровень сужает допуск, то есть «труднее» значит
*точнее*, а не *тише*.

| | Упражнение | Что вы слышите |
|:---:|---|---|
| 🎚️ | Найти частоту | Какую частоту подняли или срезали, где угодно в 100 Гц – 12,8 кГц |
| ↔️ | Положение в панораме | Где это стоит по стереополю |
| 🔊 | Изменение громкости | Насколько сдвинулся уровень, −9 … +9 дБ |
| ⏱️ | Время задержки | Какой длины эхо, 20 – 640 мс |

Остальные пять просят **назвать** вещь и всегда дают ровно два варианта, на
любом уровне. Уровень меняет, *какие* два: на первом это собор против
кладовки, на десятом — две вещи, которые правда надо уметь различать.

| | Упражнение | Между чем вы выбираете |
|:---:|---|---|
| 🥁 | Компрессия | Два из: слабая · средняя · сильная |
| 🏛️ | Реверберация | Два из: комната · камера · зал · пластина · пружина |
| 🔥 | Искажение | Два из: мягкое · жёсткое ограничение · лента · овердрайв |
| 📐 | Ширина стерео | Два из: узко · нормально · широко · очень широко |
| 🎯 | Назвать диапазон | Два из семи стандартных: суббас … воздух |

За каждым ответом стоит **семейство, а не пресет**: кафельная кабина и
большая живая комната — обе комнаты.

**Практика** без ограничений, **Выживание** даёт три жизни, **Блиц** —
девяносто секунд, где ошибка стоит пяти из них. У каждого упражнения свой
уровень. Тренироваться можно на розовом шуме, встроенных клипах или на
**своей музыке**.

## Три обучающих плагина

| | |
|---|---|
| **Learner EQ** | Графический эквалайзер: до восьми полос любого типа — колокол, полка, ФВЧ, ФНЧ, режектор — добавляются и убираются прямо на кривой. Спектр подписан не только числами, но и ощущениями: Sub, Bass, Boom, Body, Honk, Presence, Sibilance, Air. |
| **Learner Comp** | Компрессор с мягким коленом и индикатором подавления, который заполняется **вниз**, потому что именно туда идёт звук. Семь обучающих модулей — по одному на регулятор. |
| **Learner Verb** | Комната, зал, пластина и пружина, с затуханием, предзадержкой, размером, демпфированием, балансом и шириной. Свои семь модулей. |

Каждый модуль ставит свой регулятор в значение, которое вам **не
показывает**, играет его, и вы повторяете его на слух.

## Что здесь честно сказать

- Сборки **не подписаны** — система предупредит (см. ниже).
- **Ничего никуда не подключается**: нет аккаунта, сервера, телеметрии.
  Прогресс — файл на вашей машине.
- **Стемы не разделяются.** Импортированная музыка сортируется по
  измеримому характеру, а не по инструментам.
- Подсказки к параметрам, тексты уроков и обучающие модули — только на
  английском.
- Из двенадцати языков интерфейса носителем проверены только русский и
  английский.

## Как поставить

[**Скачать последнюю версию**](https://github.com/bogggare567/abcTrain/releases/latest)
— настоящий установщик под каждую систему, собранный на CI из того коммита,
на который указывает тег.

**Предупреждение честное.** Сборки не подписаны: сертификат стоит ~$99 в год
у Apple и $200–500 в год у windows-центра сертификации, и он не куплен.
Предупреждение говорит, что издатель не подтверждён, а не что с файлом
что-то не так.

- **macOS** — правый клик по `.pkg` → **Открыть** → **Открыть** ещё раз.
- **Windows** — **Подробнее** → **Выполнить в любом случае**.
- **Linux** — распаковать и запустить `./install.sh`.

Пошагово, с путями установки и тем, где живёт прогресс, —
[Установка](https://github.com/bogggare567/abcTrain/wiki/ru-Installation).
Либо **соберите из исходников** — три команды, и это тот же бинарник, но
прокликивать ничего не придётся:

```bash
git clone https://github.com/bogggare567/abcTrain.git
cd abcTrain
cmake -B build && cmake --build build
```

CMake сам скачает JUCE. На Linux сначала поставьте `libcurl4-openssl-dev`.

## Как помочь

Хорошие первые вклады: **перевод** (один JSON-файл в `shared/i18n/strings/`),
**новое упражнение** (семь шагов, в [docs/orientation.md](docs/orientation.md))
или что угодно из [планов](docs/roadmap.md).

Одно, о чём стоит предупредить: **тесты не видят раскладку.** Если вы меняете
что-то визуальное — отрендерите и посмотрите на это глазами.
