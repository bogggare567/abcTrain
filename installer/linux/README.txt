abcTrain - Ear Trainer / Learner EQ / Learner Comp / Learner Verb

To install: run ./install.sh from inside this folder. It will ask which
plugins you want and where VST3 plugins and the Standalone apps should
go - nothing is copied without you confirming it.

Manual install, if you'd rather do it yourself: each plugin's VST3 build
is in <PluginName>/VST3/, and its Standalone build is in
<PluginName>/Standalone/. Common VST3 locations on Linux are
$HOME/.vst3 (this user only) or /usr/lib/vst3 (all users, needs sudo).

Full documentation, architecture notes, and source:
https://github.com/bogggare567/abcTrain
