abcTrain - ABC Ear Trainer / ABC Learner EQ / ABC Learner Comp / ABC Learner Verb

Four plugins:

- ABC Ear Trainer - ear-training games (guess the boosted/cut band, the
  compression strength, the reverb type). Tracks points, a level that
  scales difficulty, a daily login streak, and a daily challenge.
- ABC Learner EQ - a real 4-band EQ with a live spectrum + response curve,
  a scrolling waveform, contextual tooltips, a Bypass toggle, and a
  guided Lesson.
- ABC Learner Comp - a real compressor with a live spectrum, a scrolling
  waveform with gain-reduction highlighting, GR/peak meters, 4 teaching
  presets, a Bypass toggle, and a guided Lesson.
- ABC Learner Verb - a real reverb (Room/Hall/Plate/Spring) with the same
  visualization as ABC Learner Comp, 4 teaching presets, a Bypass toggle, and
  a guided Lesson.

Each plugin has a "Check for Updates" button that checks GitHub for a
newer release - manual only, no background checks.

Full documentation, architecture notes, and source:
https://github.com/bogggare567/abcTrain

Questions or issues: please open a GitHub issue on that repository.
